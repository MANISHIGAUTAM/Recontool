## 2. Runtime truth table (selection → routing → execution)
Source of truth = code paths, verified against logs:
- **Selection** (`engine/selection.py::apply_selection`): enables curated +
  (with `--tools all`) inventory; `is_active` gated by `--authorize-active`.
  **`default_on` is INERT** — apply_selection ignores it (68/109 curated are
  default_on:false incl. assetfinder/hakrawler). *Drift: registry field unused.*
- **Routing prune** (`engine/worker.py::RouteIndex._tool_available`): drops tools
  with no binary/key BEFORE enqueue → the 153 stubs + 26 unavailable never run,
  never emit garbage. evidence: log `⊘ N tools pruned at routing`.
- **Recursion** (`runner.py::discovered_assets`): only `entity=asset` re-enqueues;
  `endpoint`/`finding`/`service` are terminal. Key types seen at runtime:
  `subdomain`, `url`, `domain`, `js_file` (after fix), `ip`/`cidr` (out-of-scope
  for a CDN domain → not recursed).
- **Token shaping** (`adapters/generic.py::_shape_tokens`): `{host}/{domain}` →
  bare host, `{url}` → scheme://host, stdin shaped. (fixed this session)
- **Execution**: per work item (one key/tool); heavy/firehose tools capped at 16
  concurrent; events batched (5000); per-tool typed output APPENDS.

## 8. Recommended staged architecture (what runs when)
- **org (stage 0)**: derive org from seed → github_org_repos, metabigor *(needs
  org producer — §6)*
- **domain (stage 1)**: subfinder, assetfinder, crtsh, hackertarget, urlscan,
  asnmap, dns_resolve, waybackurls (one wayback), shuffledns
- **subdomain (stage 2)**: httpx (hub), httpx_probe, dnsx, tlsx, massdns,
  whatweb, org_fingerprint, js-render
- **url (stage 4)**: pycrawl, katana, js_analyze, cariddi, gf-* (filters), arjun,
  unfurl
- **ip/cidr/asn (stage 3)**: cero/greynoise/internetdb/mapcidr/masscan/bgpview/
  ripestat — **only when IPs are in-scope** (direct-IP seed, or cdncheck-gated
  non-CDN IPs); skipped for CDN domains (correct)
- **js_file (stage 5, after JS harvested)**: jsluice, linkfinder, secretfinder
- **validation (stage 7, after url/live surface)**: nuclei, nikto, sslyze,
  subjack, wafw00f — gated by `--validate` + `--authorize-active`
- **NEVER in default path**: the 102 non_executable (web/awesome-lists), the 153
  uninstalled stubs, redundant duplicates (gau/gauplus/waymore/sublist3r/
  hakrawler/gospider when the primary is present)

## 9. Final proposed tool taxonomy
- **core** (always, by stage): subfinder, assetfinder, crtsh, hackertarget,
  urlscan, dns_resolve, dnsx, tlsx, httpx, httpx_probe, pycrawl, katana,
  js_analyze, js-render, jsluice, naabu/nmap, waybackurls
- **enrichment**: asnmap, org_fingerprint, unfurl, whatweb, massdns
- **validation-only** (`--validate`): nuclei, nikto, sslyze, subjack, wafw00f
- **optional/opt-in (`--tools all`)**: shuffledns, gobuster, gau, gauplus,
  waymore, sublist3r, hakrawler, gospider, cariddi, pydirb, ffuf, feroxbuster
- **terminal-only** (findings/evidence, no recursable key): nuclei, nikto, sslyze,
  whatweb, gowitness, gitleaks, sqli/gf-* filters
- **deferred (need producer/stage)**: bgpview, ripestat, github_org_repos,
  metabigor, gitleaks, epss, s3scanner, cero, greynoise, internetdb, mapcidr,
  masscan, interactsh
- **drop/reference-only**: the 102 non_executable + 153 unintegrated stubs +
  ~dozens of "Awesome *" reference pages mis-ingested as tools
